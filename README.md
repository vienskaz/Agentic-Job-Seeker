# AI Career Agent 🚀

An intelligent AI-powered career assistant that helps users find suitable job opportunities, analyze job-market fit, and optimize their resume for specific job offers.

The agent combines Large Language Models (LLMs), web scraping, and automated resume analysis to support the entire job-search workflow — from identifying suitable career paths to preparing a tailored CV.

---

## ✨ Features

### 🎯 Career Recommendation

The agent analyzes the user's resume and professional background to suggest suitable career paths and job roles.

It helps answer questions like:

- What positions should I apply for?
- Which roles match my experience?
- What career directions fit my skills?

Example:
User:
"I want to find a new job"

Agent:
Based on your experience, suitable roles are:

- Data Analyst
- Data Scientist
- Machine Learning Engineer
- Business Intelligence Analyst


---

### 🔎 Automated Job Search

The agent can search job platforms for relevant opportunities based on:

- desired position
- location preferences
- user profile

The system retrieves available job offers and extracts relevant information for further analysis.


---

### 🧠 Job Offer Matching

Each job offer can be evaluated against the candidate's resume.

The system analyzes:

- required skills
- technologies
- responsibilities
- candidate experience
- missing requirements

and determines how well the candidate matches the position.

Example:

Job Offer:
Senior Data Analyst

Match:
85%

Strong matches:
✓ Python
✓ SQL
✓ Data pipelines
✓ Analytics experience

Missing:
- Power BI experience


---

### 📄 AI Resume Tailoring

The agent can customize a resume for a specific job offer.

The optimization focuses on:

- improving keyword relevance
- highlighting matching experience
- restructuring bullet points
- improving ATS compatibility

Important:

The system does not invent experience or skills.
It only reformulates existing information from the candidate's resume.
